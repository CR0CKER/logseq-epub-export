**Read your Logseq graph like a book.** Logseq EPUB Export turns the open graph into one navigable EPUB for e-readers — built for KOReader on e-ink devices, where Markdown shows up as plain text and `[[wikilinks]]` can't be tapped.

![The export panel in Logseq](https://raw.githubusercontent.com/CR0CKER/logseq-epub-export/v0.1.0/screenshots/panel.png)

## Highlights

- **Export from a small panel:** the toolbar icon opens it, **Export now** exports the current graph; it follows your theme and closes with × or Esc. The command palette also has a direct export.
- **Everything links:** `[[wikilinks]]` and aliases become tappable links, every `#tag` gets an index chapter, and each page ends with its Linked References.
- **Your pictures come along:** images from the graph are embedded, downscaled to e-reader size so the book stays small. Web images stay links.
- **Index pages come alive:** `{{query (property type "…")}}` blocks expand into real lists.
- **Easy to find your way around:** a Home chapter and a Pages / Tags / Journals table of contents that KOReader shows natively.
- **A cover made for e-ink:** light, high-contrast, titled with your graph's name, and written as a JPEG so KOReader displays it.
- **Named like Calibre names it:** `<graph> - Logseq EPUB Export.epub`, so a direct export and a Calibre copy share a name and KOReader's reading history.
- **Save where you want:** into the graph's assets folder (synced with it), or a folder you pick on the first export and that is remembered per graph.
- **Works with both kinds of Logseq:** file graphs on Logseq 0.10.x and DB graphs on Logseq 2.x.

## Install

1. Download `logseq-epub-export-v0.1.0.zip` below and unzip it.
2. In Logseq: **Settings → Advanced → Developer mode** on, then **Plugins → Load unpacked plugin** and pick the unzipped folder.
3. Click the book icon in the toolbar, then **Export now**.

On a file graph the EPUB is saved to `<graph>/assets/storages/logseq-epub-export/`. If you sync that folder with Syncthing, the book reaches your e-reader on its own. DB graphs save under `~/logseq/graphs/<graph>/assets/storages/logseq-epub-export/`, or pick your own folder with **Save destination → custom-folder**.

## Known limitations

- The book is a snapshot; export again after editing.
- Web images stay links; PDFs and other attachments are not embedded.
- Block references and embeds are not resolved.
- Only `(property key "value")` queries are expanded.
- **Choosing the root of Downloads, Documents or Desktop (or your home folder) as the custom folder gets the picker stuck** — Logseq never answers Electron's question about protected folders. Restart Logseq and choose a folder inside one of them.

## Behind the scenes

- A live test suite drives real Logseq 0.10.15 and Logseq 2.0.1 (unpacked and installed like a release zip), exports a seeded graph and checks the book — container, XHTML, links, tags, backlinks, headings, properties, journals, images, cover, file name — and the panel, folder picker, settings, theming and keyboard.
- `npm audit` reports no known vulnerabilities. The plugin SDK is `@logseq/libs` 0.3.4, with patched `dompurify` and `lodash-es`.
